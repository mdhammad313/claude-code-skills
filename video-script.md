# LinkedIn Video Script
**Title:** Claude Code Skills Nobody Talks About
**Length:** 90 seconds
**Tone:** Casual, direct
**Demo skill:** /onboard-me (most visual wow factor)

---

## HOOK (0–8s)
**[Screen: terminal, no face cam needed]**

> "Most developers use Claude Code like a chatbot.
> But there's a feature that lets Claude remember HOW you work — forever.
> It's called Skills. Let me show you."

---

## PROBLEM SETUP (8–20s)
**[Screen: show typing the same long prompt repeatedly or pasting instructions]**

> "Every time you start a session, you're re-explaining yourself.
> Your coding standards. Your workflow. How to run the project.
> It gets old fast."

---

## INTRODUCE SKILLS (20–35s)
**[Screen: show the claude-code-skills repo on GitHub briefly, then open terminal]**

> "Skills let you write those instructions ONCE — as a markdown file —
> and Claude follows them every single session.
> No copy-pasting. No re-explaining.
> Just type slash and the skill name."

---

## LIVE DEMO — /onboard-me (35–70s)
**[Screen: open a codebase the viewer doesn't know, type /onboard-me]**

> "Here's my favourite one. I just cloned a repo I've never seen before.
> I type /onboard-me..."

**[Screen: show Claude reading files, running git log, scanning configs — let it run]**

> "It reads the actual codebase. Git history. Config files. Entry points.
> And gives me a full onboarding guide — architecture, key files, gotchas,
> how to run it locally..."

**[Screen: scroll through the output — make it feel fast and impressive]**

> "In under a minute. From a codebase I'd never touched."

---

## CALL TO ACTION (70–85s)
**[Screen: show GitHub repo URL or README]**

> "I built four of these skills and put them on GitHub — free, open source.
> onboard-me, rubber-duck debugging, explain-to-pm, and a tech debt radar.
> Link's in the comments."

---

## CLOSER (85–90s)
**[Screen: stay on terminal or repo]**

> "If you use Claude Code, this will save you hours.
> Go grab it."

---

## RECORDING TIPS

- Record at 1080p, crop to portrait (9:16) for LinkedIn native video
- Move slowly through the demo — viewers need time to read the output
- Add captions (LinkedIn auto-generates, but clean them up)
- Keep cursor visible and moving — it shows you're actually doing it live
- No need for face cam — screen recording + voiceover performs just as well
